03 · A área e as carreiras

O que faz quem trabalha com dados

Trabalhar com dados tem três carreiras: analisar e modelar dados para apoiar decisões (ciência de dados e analytics), construir pipelines e plataformas distribuídas de Big Data (engenharia de dados) e modelar, sustentar e integrar bancos de dados e data warehouses (banco de dados). Os MBAs aprofundam cada uma delas, com Power BI, R, KNIME e SQL na análise; SQL avançado, dbt, Spark SQL, Delta Lake e Kafka nos pipelines; SQL Server 2025, Azure SQL, Oracle 26ai, MongoDB e BigQuery nos bancos e no warehouse. Relatórios e consultas simples já podem ser feitos com IA; ganha valor quem interpreta os dados, recomenda e constrói a base confiável para a IA funcionar.

Cargos
  • Cientista de Dados · Analista de Modelagem Preditiva
  • Analista de Dados Sênior (Data Analyst) · Analista de BI e Analytics · Analytics Engineer
  • Data Engineer · Senior Data Engineer · Data Platform Engineer · MLOps Engineer / ML Platform Engineer
  • Database Engineer / DBA moderno (com foco em cloud, performance e alta disponibilidade)
  • Data Architect / Data Platform Architect

Dúvidas de quem está comparando

As aulas são ao vivo?

Segundo o documento de diferenciais do Infnet, todas as aulas são 100% ao vivo, síncronas, com data e hora para acontecer; não é um modelo híbrido nem 'a maioria das aulas'.

Qual a diferença entre ciência de dados, engenharia de dados e banco de dados?

Ciência de dados analisa e modela dados para apoiar decisões (estatística, machine learning, Power BI, R, KNIME). Engenharia de dados constrói e opera plataformas e pipelines de Big Data (SQL avançado, dbt, Spark SQL, Delta Lake, AWS Glue, Kafka). Banco de dados e data warehouse trata de modelagem, performance, alta disponibilidade, cloud e BI (SQL Server 2025, Azure SQL, Oracle 26ai, MongoDB, BigQuery, dbt, Power BI).

Preciso de conhecimento técnico prévio?

No MBA em Data Science, a página indica quem trabalha com dados, BI, marketing ou finanças e também quem quer migrar para a área, mesmo sem domínio de programação. Engenharia de Dados pede base em programação e SQL. Banco de Dados e DW pede conhecimentos prévios em bancos de dados.

Os três têm 1 ano, com aulas das 20h00 às 22h00. Data Science: 02/02/2027 (ter e qui). Engenharia de Dados e Banco de Dados: 01/02/2027 (seg e qua).
